Elemen Fungsi Contoh

Elemen JavaScript

Variabel

Digunakan untuk menyimpan data. Contoh: let x = 10;

Array

Struktur data yang dapat menyimpan banyak nilai. Contoh: let arr = [1, 2, 3];

Objek

Struktur data yang menyimpan pasangan kunci-nilai. Contoh: let obj = {nama: "Ali", umur: 25};

Fungsi JavaScript

Fungsi Deklaratif

Fungsi yang dideklarasikan dengan kata kunci function. Contoh: function greet() { alert("Halo!"); }

Fungsi Ekspresi

Fungsi yang disimpan dalam variabel. Contoh: const greet = function() { alert("Halo!"); };

Arrow Function

Fungsi dengan sintaks yang lebih ringkas. Contoh: const greet = () => alert("Halo!");
